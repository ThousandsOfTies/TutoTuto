# TutoTutoの軽量化と測定結果

2026-09-06に、SNSアイコンの限定とHEIC・教材編集の遅延読み込みを実装。
共通ライブラリと各アプリの設定をTutoTuto・DoriDori・CopiCopiへ反映した。

## 実装内容

- SNSアイコンは使用する15種類だけを名前付きimport。Amazonの独自SVGと未登録サイトのフォールバックを維持。
- HEIC/HEIF変換は該当形式の画像を選んだ時だけ読み込む。JPEG/PNGでは読み込まない。
- 教材編集は編集を開いた時、画像からPDFへの変換は画像取り込み時に読み込む。
- 編集の読み込み中表示、失敗時の案内、教材一覧へ戻る操作を追加。
- ブラウザーは失敗したimportを記憶するため、編集の再試行では対象教材のIDを保持してページを読み直す。画像取り込みの失敗時も再読み込み後に画像を選び直すよう案内。
- ビルドの依存グラフから編集・変換専用の資産を特定し、PWAの事前キャッシュから除外。通常の学習や採点結果のキャプチャに必要な共有コードは事前キャッシュを維持。
- 追加資産は使用時にアプリ別のキャッシュへ保存する（上限64ファイル、90日）。

## 本番ビルドの比較

各アプリの変更前後を同じローカル依存環境で比較。単位は10進MB。
メインJavaScriptの実ファイルサイズで、アプリ全体の通信量ではない。

| アプリ | 変更前 | 変更後 | gzip圧縮前後 |
|---|---:|---:|---:|
| TutoTuto | 8.833 MB | 1.333 MB | 3.168 → 0.365 MB |
| DoriDori | 8.619 MB | 1.123 MB | 3.109 → 0.307 MB |
| CopiCopi | 8.862 MB | 1.362 MB | 3.177 → 0.374 MB |

TutoTutoではメインJavaScriptが約85%、gzip圧縮後が約88%減少。
編集と変換のコードは必要時に追加取得する。
画像、PDFワーカー、既存のOpenCVスクリプト等の通信はこの数字に含めない。
実端末の起動時間は未測定で、同じ割合の高速化を保証するものではない。

## オフラインでの利用

教材一覧・通常の学習に必要な資産は引き続き事前キャッシュする。
編集・画像取り込み・HEIC変換を初めて使う際はオンライン接続が必要。
一度使った機能は、必要な資産がキャッシュに残っている間はオフラインでも利用できる。
アプリ更新で資産のハッシュが変わった場合や、端末がキャッシュを削除した場合は再取得が必要。
教材や筆跡を削除する変更、IndexedDBの名前・バージョン変更はない。

## 検証

- 3アプリの型チェック、本番ビルド、生成物の依存・キャッシュ分離チェックが成功。
- SNSアイコン、HEICの条件付き読み込み、読み込み失敗の案内、編集への復帰、共有依存をキャッシュに残す処理を回帰テストへ追加。
- GitHub Actionsで生成物のキャッシュ分離も検証する。
- TutoTutoのローカル検証サーバーで初回表示時の追加資産リクエストが0件であることを確認。
- 編集ファイルの取得に503を返すテストで、失敗表示と接続復帰後の再試行による同じ教材の表示を確認。
- その後サーバーの全リクエストを503にしてページを再読み込みし、キャッシュ済み編集画面の表示、回転編集・保存を確認。

## 未実施の改善案

StudyPanel内の切り抜き、採点と履歴保存、描画保存、画面遷移の分割は今回の対象外。
主な効果は保守性と不具合予防であり、ファイル分割だけで速度が改善するものではない。
